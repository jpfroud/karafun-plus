# File karaoké — règles de travail

gstack est obligatoire pour les changements de code : utiliser `investigate` pour un défaut, `qa` pour les parcours navigateur et `review` avant livraison. L'utilisateur a demandé qu'il s'installe tout seul : au démarrage de chaque session, le hook `.claude/hooks/gstack-session-start.sh` lance `install-gstack.sh` si gstack manque (clonage officiel puis `./setup --team`), et le même hook rappelle le parcours à chaque demande (`UserPromptSubmit`). Si l'installation échoue (`GSTACK_MISSING`), donner la raison à l'utilisateur avant tout changement de code et réessayer avec `bash .claude/hooks/install-gstack.sh`. Le hook `check-gstack.sh`, sur le modèle officiel `gstack-team-init required`, refuse les compétences tant que gstack manque. Un sous-agent chargé d'un changement de code suit le même parcours.

Après toute modification de la file, des duos, des présences ou des tables, lancer `node test/run-offline.js` et consigner le résultat dans `RAPPORT-TEST.md`. Le vrai KaraFun ne doit pas servir aux essais destructifs si son code de télécommande actuel n'a pas été vérifié.
